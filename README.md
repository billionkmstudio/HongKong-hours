# Hong Kong Hours
Interactive procedural 3D Hong Kong harbour scene (Three.js). Live: https://hongkong-hours.billionstudio.co.uk
Deploy: upload this folder as its own Vercel project (Framework: Other, no build), add the domain hongkong-hours.billionstudio.co.uk.
Local test: `python3 -m http.server 8080` (do not open via file://).
Files: index.html, engine.js (shared engine), cities/hongkong.js (city config), paintings/, og.jpg.
